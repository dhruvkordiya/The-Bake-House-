## 🚀 How to Use

1. Open `index.html` in a web browser
2. Browse menu items or use search feature
3. Select quantity and add items to cart
4. Click cart icon to view your order
5. Click "Pay" button to checkout
6. Fill in delivery details
7. Confirm order
